# Display Switch

**Per-game display settings for Windows.**

HDR, resolution and scaling switch when a game starts, and switch back when it closes.

[Download](https://github.com/sxnfer/game-display-switch/releases/latest) · [Using it](docs/using-it.md) · [How it works](docs/how-it-works.md)

</div>

<br>

| Feature | What it does |
| --- | --- |
| **HDR** | On the moment you press Play, back to SDR 3 seconds after you quit. |
| **Competitive resolution** | A smaller, centred play area per game, with an optional stretched resolution inside it. [More](docs/competitive-resolution.md) |
| **NVIDIA scaling** | Switched to No scaling while the game runs, restored after. |
| **Recording** | Stays in SDR while OBS or Streamlabs runs. [More](docs/recording.md) |

Finds your games on its own: Steam, Epic, GOG, Ubisoft Connect and game folders on every drive.

## Get started

1. Download **HdrSwitch.exe** from the [latest release](https://github.com/sxnfer/game-display-switch/releases/latest).
2. Run it. Windows may warn that it isn't code-signed: **More info › Run anyway**.
3. Click the tray icon and turn on **Start with Windows**.

Windows 10 or 11 · No install · ~0.2% of one CPU core · ~20 MB

<sub>Every release is built by GitHub Actions from this repository and ships with its SHA-256 checksum.</sub>
